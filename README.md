# LUX

واحد مدیریت درس‌ها و تحصیل شخصی — اپ اندروید (Flutter).

## ساخت APK (از طریق GitHub Actions)

1. یک مخزن (repo) روی GitHub بساز و کل محتویات این پوشه را در شاخه‌ی `main` آپلود کن
   (پوشه‌ی `.github` هم باید باشد).
2. بخش **Actions → Build LUX APK → Run workflow** را بزن (با هر push هم خودکار اجرا می‌شود).
3. بعد از پایان، از بخش **Releases** (سمت راست صفحه‌ی اصلی مخزن) آخرین نسخه را باز کن و فایل `lux.apk` را مستقیم دانلود کن (بدون زیپ).
   نسخه‌ی زیپ‌شده هم در **Actions → اجرای مربوطه → Artifacts → `lux-apk`** هست.
4. APK فقط برای گوشی‌های ۶۴ بیتی (arm64) ساخته می‌شود تا حجمش کم باشد (~۱۰ تا ۱۲ مگابایت).

## کلید امضا (برای اینکه آپدیت‌ها روی نصب قبلی بنشینند)

یک‌بار روی کامپیوتر:

```
keytool -genkeypair -v -keystore lux.jks -alias lux -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 lux.jks
```

سپس در GitHub: **Settings → Secrets and variables → Actions** چهار Secret بساز:

| نام | مقدار |
|---|---|
| `KEYSTORE_BASE64` | خروجی دستور base64 |
| `KEYSTORE_PASSWORD` | رمز keystore |
| `KEY_ALIAS` | `lux` |
| `KEY_PASSWORD` | رمز کلید |

فایل `lux.jks` را در چند جای امن نگه دار؛ اگر گم شود، دیگر نمی‌شود آپدیت داد.

## ساختار

- `lib/core` پالت، تم، ابزار تاریخ شمسی
- `lib/data` پایگاه‌داده‌ی SQLite (طرح کامل همه‌ی ماژول‌ها)
- `lib/engine` موتور محاسبات (معدل، نمره‌ی لازم، برنامه‌ریز، SM-2، آمار)
- `lib/ui/charts` نمودارهای اختصاصی
- `lib/ui/onboarding` اولین اجرا
- `tool/` اسکریپت‌های ساخت (CI)

## تغییرات نسخه‌ی ۱٫۱

- حذف کاملِ داده‌ی نمونه/فیک از «تحلیل»؛ نمودارها فقط با داده‌ی خودت ساخته می‌شوند.
- انیمیشن لوگوی شروع از نو نوشته شد (بدون لگ، لوگو در بالا بزرگ‌تر می‌ماند و برق‌زدن نقره‌ای دارد).
- ویبره از موتور لرزش خودِ گوشی (native) استفاده می‌کند + دکمه‌ی «آزمایش ویبره» در پروفایل.
- اعلان‌ها: دسترسی‌ها از خودِ اندروید پرسیده می‌شود، آیکون اعلان اختصاصی، و R8 در نسخه‌ی release برای پلاگین اعلان خاموش شد.
- فونت جدید: Estedad (جایگزین: Vazirmatn)، عنوان‌ها Lalezar، امضا Michroma.
- حذف «محل پایگاه‌داده» از پروفایل؛ امضای «By Pishva System» با لوگوی پیشوا در انتهای پروفایل.

## امکانات نسخه‌ی ۱٫۲

- **درس‌ها**: ساخت و ویرایش درس (ضریب، سختی، معلم، رنگ)، نمره‌ها و میانگین، نمره‌ی لازم برای رسیدن به هدف، ساعت کلاس‌ها.
- **معلم‌ها، کتاب‌ها (با فصل و پیشرفت)، مثبت‌ها و اخطارها**: هرکدام لیست کامل با افزودن، ویرایش و حذف.
- **برنامه**: امتحان‌ها (ثبت نمره، لغو، یادآور)، تقویم، جدول کلاس‌ها، تکالیف و پومودورو.
- **رمز ورود** (۴ یا ۶ رقمی) از بخش پروفایل ← امنیت.
- **فایل داده**: پروفایل ← داده‌ها و پشتیبان. همه‌ی اطلاعات در یک فایل JSON ذخیره/بازیابی می‌شود و یک نسخه‌ی خودکار هم همیشه به‌روز است.
- **ویبره** با کاربرد «آلارم» تا روی حالت بی‌صدا هم کار کند.

## تغییرات نسخه‌ی ۱٫۳

- **کتاب‌ها داخل هر درس‌اند** (دیگر لیست جداگانه ندارند)؛ هنگام ساخت درس می‌شود نامِ کتاب را هم نوشت.
- **ظاهر و شخصی‌سازی** (پروفایل ← ظاهر): حالت روشن / خودکار / تیره، ۵ تم رنگی (فیروزه‌ای، بنفش، زمردی، کهربایی، سرخابی)، اندازه‌ی متن، ویبره و انیمیشن ورود.
- **ورود با اثر انگشت** (پروفایل ← امنیت؛ بعد از فعال‌کردن رمز).
- **انیمیشن ورودِ LUX** در هر بار باز شدن برنامه (قابل خاموش‌کردن).
- **خلاصه روزانه**: اعلانِ کاملِ برنامه‌ی هر روز (کلاس‌ها، امتحان‌ها، تکالیف، تولد، پیشنهاد)؛ روشن/خاموش، ساعت ارسال و انتخاب محتوا از پروفایل ← اعلان‌ها.
- شماره‌ی معلم دیگر پرسیده نمی‌شود و دکمه‌ی آزمایش ویبره برداشته شد.

## تغییرات نسخه‌ی ۱٫۴

- **بازطراحی ثبت درس، امتحان و تکلیف**: فرم‌ها کوتاه شدند (درس با چیپ انتخاب می‌شود، تاریخ با دکمه‌های «فردا / ۳ روز دیگر / هفته‌ی بعد»، بقیه‌ی فیلدها زیر «گزینه‌های بیشتر»).
- هر درس یک صفحه‌ی کامل دارد: امتحان، تکلیف، نمره، کتاب و ساعت کلاس همان‌جا کنار هم‌اند. معلم را همان‌جا با نوشتنِ اسمش تعریف می‌کنی.
- تبِ «برنامه» چهار بخش دارد: پیش‌رو، امتحان‌ها، تکالیف، کلاس‌ها.
- دکمه‌ی گرد «+» در صفحه‌ی «امروز» برای افزودنِ سریعِ هر چیزی.
- آیکون اعلان‌ها لوگوی LUX شد (سیلوئت تک‌رنگ + لوگوی رنگی کنار اعلان).
- گزینه‌ی «ورود با اثر انگشت» همیشه در بخش رمز دیده می‌شود و اگر مشکلی باشد دلیلش را می‌گوید.

## تغییرات نسخه‌ی ۱٫۵

- **درس‌های آماده‌ی پایه و رشته**: برای رشته‌های تجربی، ریاضی و فیزیک و انسانی (پایه‌های دهم تا دوازدهم) فهرست کامل دروس همراه با ضریب سوابق تحصیلی کنکور داخل برنامه ذخیره است (`lib/data/curriculum.dart`).
- بعد از انتخاب رشته و پایه می‌پرسد: «از روی فهرست اضافه کنم یا خودت اضافه می‌کنی؟». برای هر ترکیب رشته + پایه یک‌بار خودکار می‌پرسد، و هر وقت پایه یا رشته را از پروفایل عوض کنی دوباره.
- این گزینه همیشه در دسترس است: درس‌ها ← «درس‌های آماده‌ی پایه و رشته» (و دکمه‌ی همین کار در صفحه‌ی خالیِ درس‌ها). درس‌هایی که از قبل داری دوباره اضافه نمی‌شوند و می‌شود هر درس را تیک زد یا برداشت.
- درس‌هایی که در جدول ضریب ندارند با ضریب ۱ اضافه می‌شوند (قابل ویرایش).

## تغییرات نسخه‌ی ۱٫۶

- **رقابت** (درس‌ها ← بیشتر ← رقابت): با یک کلید روشن/خاموش می‌شود. روشن که شد، اسم رقبا را می‌نویسی (چند اسم را می‌شود یک‌جا نوشت).
- هنگام «ثبت نمره»ی هر امتحان، زیرِ نمره‌ی خودت نمره‌ی هر رقیب هم نوشته می‌شود؛ **اختیاری** است و خالی‌گذاشتن یعنی «نمره‌اش را نمی‌دانم».
- **نمودارِ خطِ شکسته**: «سطح کلی» (میانگینِ ضریب‌دار تا هر امتحان) و «سطح در هر درس» (نمره‌ی هر امتحانِ آن درس) بین خودت و رقبا؛ با لمس همه‌ی مقدارها مرتب‌شده دیده می‌شود. رقبا را می‌شود از نمودار پنهان/نمایان کرد و با «فقط امتحان‌های مشترک» فقط امتحان‌هایی را حساب کرد که همه نمره دارند.
- جدول مقایسه: رتبه‌ی تو بین رقبا و اختلافِ هر رقیب با خودت.
- پایگاه‌داده به نسخه‌ی ۲ رفت (دو جدول تازه)؛ داده‌ی قبلی دست‌نخورده می‌ماند و رقابت در فایل پشتیبان هم ذخیره می‌شود.
